# listed. A name on this list is a promise that the source build has been dealt with -
# so the reason has to say how, not just that it was noticed.
#
# Format: name  # reason

            # https://pypi.nvidia.com/ and the launcher uses --no-build-isolation, so the
            # stub selects NVIDIA's prebuilt CPython 3.12 manylinux x86_64 wheel.
